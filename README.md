## Описание проекта

Проект автоматизирует тестовые сценарии для веб-сервиса «Доска», предоставленные ручным тестировщиком. Основные цели:
*   Проверка функциональности регистрации и авторизации пользователей.
*   Проверка негативных сценариев при регистрации.
*   Проверка работы с объявлениями (создание, проверка видимости).

## Функциональности, покрытые тестами

### Сценарии регистрации и авторизации
1.  **Успешная регистрация нового пользователя**
    *   Проверка перехода на главную страницу и отображения аватара/имени пользователя после регистрации.

2.  **Неуспешная регистрация с email не по маске**
    *   Проверка подсветки полей красным цветом и отображения сообщения об ошибке.

3.  **Неуспешная регистрация уже существующего пользователя**
    *   Проверка подсветки полей красным цветом и отображения сообщения об ошибке.

4.  **Успешный вход (Login) существующего пользователя**
    *   Проверка перехода на главную страницу и отображения аватара/имени пользователя после входа.

5.  **Успешный выход (Logout) пользователя**
    *   Проверка, что после выхода отображается кнопка «Вход и регистрация», а аватар и имя пользователя скрыты.

### Сценарии работы с объявлениями
6.  **Попытка создания объявления неавторизованным пользователем**
    *   Проверка отображения модального окна с предложением авторизоваться.

7.  **Успешное создание объявления авторизованным пользователем**
    *   Заполнение всех полей формы, публикация и проверка, что объявление отображается в профиле пользователя.

## Технологический стек

*   **Язык программирования:** Python 
*   **Фреймворк для автоматизации:** Selenium WebDriver
*   **Фреймворк для тестирования:** Pytest
*   **Браузер:** Chrome / ChromeDriver
